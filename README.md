# PhonePe-Pulse-Dashboard
This project presents an interactive Power BI dashboard built using the PhonePe Pulse dataset, showcasing digital payments insights across India. It highlights how payments are distributed by user, device brands, transaction type, states, and total monetary value.
Dashboard Highlights
Metric	Value
Total Users: 206M
CAGR:	150.85%
Avg. Transaction:	1.64K
Total Transactions:	39 Billion
Total Payment Amount:	₹64.27 Trillion

📌 Key Insights Visualized
1. Transactions by Payment Type
-> Pie-chart showing share of digital transactions across:
-> Peer-to-Peer
-> Merchant Payments
-> Recharge & Bill Payments
-> Others
-> Financial Services

2. Top States by Transaction Amount
Bar graph ranking states in terms of transaction volume, highlighting the highest contributors such as Telangana, Maharashtra, and Karnataka.

3. Year-wise Digital Payment Growth
Column chart representing total payment amount for selected year — showing overall national growth trend.

4. Brand-wise Usage & Transaction Summary
-Table comparing device brands with:
-Total Registered Users
-Total Transactions Generated
-Total Payment Value (Major contributors include Xiaomi, Samsung, OnePlus & Others)

5. State-wise Geo Distribution
India map visualization displaying digital payment penetration across states with color-coded transaction density.
